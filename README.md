# BookingSystem

Backend-приложение для бронирования переговорных комнат на Java и Spring Boot.

A room booking backend application built with Java and Spring Boot.

## Технологии

- Java 25
- Spring Boot 4.2.0
- Spring Web MVC
- Gradle
- JUnit 5

## Текущее состояние

Инициализирован Spring Boot-проект

## Запуск

```bash
./gradlew bootRun
```

## Тестирование

```bash
./gradlew test
```
